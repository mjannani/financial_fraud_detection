# Financial Fraud Detection & Risk Analytics

## Run the Streamlit app

1. Install Python 3.10 or newer.
2. Open Command Prompt/PowerShell in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the application:

```bash
streamlit run app.py
```

5. Upload your Zidio CSV/XLSX fraud dataset from the sidebar.

## Dashboard modules

- Executive Overview
- Data Analysis / EDA
- Fraud Analysis
- Model Training
- Logistic Regression
- Random Forest
- SMOTE balancing
- Model Performance
- Confusion Matrix
- ROC-AUC
- Feature Importance
- Batch Risk Prediction
- Dataset Explorer

## Important

The application automatically looks for a likely fraud/target column. You can manually select the target column in the sidebar.

For the best final project, use the actual dataset supplied by your organization and report the model results produced by your own run.
